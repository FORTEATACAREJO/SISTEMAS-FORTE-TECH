Homologação — sem envio real
Esta é uma prévia com clientes fictícios. Não insira dados de clientes reais nesta demonstração. O envio e agendamento ficam desativados até integrar serviço seguro, aprovações, descadastro e controles do provedor.

1. Escolha os grupos de clientes

Uma campanha para vários clientes; cada pessoa receberá individualmente quando o disparo estiver habilitado.

O sistema verificará o aceite específico de cada cliente para receber ofertas neste canal.

2. Monte sua promoção

Dados de preços, produtos e validade são informados pelo operador e deverão ser validados antes de enviar.

4. Proteção dos clientes

  • Endereços não são revelados a outros clientes.
  • Clientes descadastrados ou sem permissão são excluídos.
  • Duplicados são removidos antes de preparar.
  • Campanhas reais exigem aprovação e registro.
  • Descadastro deve ser processado antes de novos disparos.

Em um disparo futuro, cada cliente receberá uma mensagem particular, não um grupo público.
